# Agent Orchestration

## Process

1. Split work by domain and file ownership.
2. Give each agent a specific write scope.
3. Require evidence, assumptions, and open questions.
4. Ask agents to avoid rewriting unrelated sections.
5. Route final integration through the lead thread or human operator.

## Standard Agent Domains

- Market and acquisition research
- Financial model and unit economics
- Operations and project management
- People pipeline and training
- Sales and marketing
- Legal, risk, and compliance checklist
- Investor narrative
- Agentic operating system
