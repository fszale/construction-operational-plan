# Universal Agent Guide

Agents should behave like practical operating partners. The goal is to produce a clear, usable business blueprint that can become an operating company, acquisition vehicle, or investor-facing concept.

## Work Style

- Be concrete.
- Mark assumptions.
- Separate evidence from inference.
- Prefer repeatable systems over one-time goals.
- Prioritize the 20 percent of operating changes likely to produce 80 percent of value.
- Keep legal, tax, employment, licensing, insurance, and deal-structure issues flagged for professional review.

## Required Output Shape

For substantial work, end with:

- files changed
- assumptions added or modified
- open questions
- recommended next tasks
