# Session Closeout

At the end of a meaningful work session:

1. Update changed canonical plan files.
2. Add new assumptions to `00-overview/assumptions.md`.
3. Add decisions to `07-execution-plan/decision-log.md`.
4. Add unresolved issues to `00-overview/open-questions.md`.
5. Update `.agents/context/current-facts.md` if stable context changed.
6. Save reusable learning in `.agents/sessions/summaries/YYYY-MM-DD-session-summary.md`.
7. Update `.agents/INDEX.md` and `.agents/registry.yaml` only when adding reusable skills, prompts, templates, or artifacts.
