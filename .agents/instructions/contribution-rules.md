# Contribution Rules

## Human Contributors

- Put raw notes in `09-contributor-workspace/`.
- Comment on assumptions, risks, missing data, and execution feasibility.
- When proposing a change, include why it matters and what would validate it.

## Agent Contributors

- Use `.agents/registry.yaml` to find canonical files.
- Do not overwrite another agent's assigned work area.
- Prefer adding dated drafts over silently replacing large sections.
- Add unresolved questions instead of inventing missing facts.
