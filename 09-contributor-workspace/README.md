# Contributor Workspace

This folder is for rough work that should not yet be treated as canonical plan content.

## Use This Folder For

- voice notes
- research notes
- early drafts
- review requests
- candidate-owner notes
- contributor comments

## Folder Map

```text
voice-notes/       Raw dictated notes and transcripts
research-notes/    Market, competitor, trade, finance, and owner research
drafts/            Draft documents before promotion to canonical folders
review-requests/   Specific questions or files for people to review
```

## Promotion Rule

When a draft becomes reliable enough to affect the plan:

1. Move the stable content into the appropriate numbered folder.
2. Add assumptions to `00-overview/assumptions.md`.
3. Add decisions to `07-execution-plan/decision-log.md`.
4. Leave the rough source here if it helps preserve context.
