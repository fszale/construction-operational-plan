# Software Stack

## Initial Requirements

The first operating stack should support:

- CRM and lead intake
- call tracking
- form tracking
- scheduling
- estimating and quoting
- project management
- customer communication
- job costing
- bookkeeping integration
- document storage
- KPI dashboard
- agent-accessible structured data

## Selection Criteria

- simple enough for field adoption
- mobile-friendly
- supports photos and job notes
- integrates with accounting
- provides exportable data
- supports role-based access
- does not require custom software before proof of concept

## Open Software Categories

- CRM
- construction project management
- estimating
- accounting
- payroll
- HR/recruiting
- call tracking
- analytics dashboard
- knowledge base
